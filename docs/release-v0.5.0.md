# 大肥鱼回收站桌宠 v0.5.0

Windows 桌面回收站小助手，默认鲸鱼娘，奶蛙备选。

- 有效拖放按砸文件、吞咽交替，分别播放 chovy 与 token 配音。
- 文件图标或图片缩略图随动作移动，吞咽时逐渐进入嘴巴。
- 动画完成后调用 Windows 系统回收站，支持正常还原。
- 启动时自动用自建小文件验证回收、恢复和内容一致；失败时只开放演示。
- 默认窗口 225×255 个 WPF 逻辑像素，为原版宽高的 50%。

下载附件 `RecyclePet-Windows-v0.5.cmd` 后双击运行，更新前退出旧桌宠。等待自检通过后将本地普通文件拖入角色。右键可切换角色、静音、打开回收站或退出。

运行要求：Windows 10/11、Windows PowerShell 5.1、.NET Framework WPF；无需开发 SDK、管理员权限或 API 密钥。

当前范围：本地固定 NTFS 磁盘普通文件，一次 1～20 个；暂不支持文件夹、网络／移动磁盘、云占位文件及链接。
